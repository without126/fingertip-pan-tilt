# ESP32串口云台控制固件

该固件接收电脑通过USB串口发送的指尖目标，并使用PCA9685平滑控制CH0和CH1。它保留实物校准结果：CH0中位317、安全范围215～419；CH1中位307、安全范围205～409。CH2～CH15始终关闭。

## 串口协议

- `T,317,307`：设置CH0和CH1目标计数。
- `CENTER`：两个轴限速回到各自校准中位。
- `DISABLE`：立即把全部16个PCA9685通道设为FULL_OFF。
- `PING`：ESP32回复`PONG`，用于检查串口。

每条命令必须以换行符结束。即使电脑发送超出范围的目标，ESP32也会再次执行安全限位。如果700毫秒没有收到新的运动命令，两个轴会自动回中。

## 上传和运行

上传前关闭外部5V并关闭PlatformIO串口监视器。上传成功后打开监视器，确认出现`READY_FOR_FINGERTIP_COMMANDS`且没有`ERROR`。正式运行Python程序时必须关闭串口监视器，因为同一个COM端口不能同时被两个程序占用。

第一阶段不要安装或开启激光笔，只观察云台是否跟随手指。出现机械碰撞、持续嗡鸣、异常发热或电源反复重启时，应立即关闭外部5V。
