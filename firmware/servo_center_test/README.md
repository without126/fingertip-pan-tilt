# PCA9685云台最终双舵机最大幅度测试程序

该固件将PCA9685配置为校准后的约50Hz，并使用两个轴各自的校准中位：CH0为317计数，CH1为307计数。CH0围绕317在215～419之间摆动，CH1围绕307在205～409之间摆动；两个轴的端到端理论摆角都约为90度。每改变一个PWM计数等待20毫秒，速度约为上一轮60毫秒版本的3倍。程序依次测试CH0和CH1，只执行一轮，最后让两个轴回到各自的校准中位；CH2～CH15始终关闭。

初始化会无条件清除MODE1的SLEEP位并读回验证，修复“寄存器写入正常但PWM振荡器仍处于睡眠”的问题。分频值根据GPIO7实测结果从121校准为127，使当前这块模块输出的脉冲更接近目标宽度。

## 上传前

- 外部5V舵机电源保持关闭
- 拔掉此前黄色PWM到ESP32 GPIO7的回读线
- PCA9685的OE直接连接PCA9685 GND，确保输出被启用
- 在CH0和CH1各连接一个MG90S：棕线接黑色GND、红线接红色V+、橙线接黄色PWM
- 云台底座放稳；确认舵机线有余量，不会被转轴拉扯或卷入支架
- 激光笔暂时不要安装或开启
- ESP32与PCA9685按VCC、GND、SDA、SCL四根逻辑线连接

## 安全判据

先关闭外部5V，通过USB上传程序并打开串口监视器。只有看到`READY_FOR_FINAL_MAX_RANGE_TEST`且没有任何`ERROR`后，才接通外部5V。测试过程中手应放在电源插头附近；如果支架碰到限位、舵机持续嗡鸣、堵转、拉扯电线或明显发热，应立即关闭外部5V。看到`FINAL_MAX_RANGE_TEST_FINISHED_BOTH_AXES_HOLDING_CENTER`后表示一轮测试完成。

源代码中的中文注释详细解释了PCA9685寄存器地址、位运算、50Hz分频、4096级PWM以及FULL_OFF安全机制。
